# mrsleeg.com

The website of Mrs Lee G: juggling, sewing on a hot pink sewing machine, drawing, and videos about tech with three balls in the air.

Built with [Hugo](https://gohugo.io) (0.168), no theme, no JavaScript, deployed to GitHub Pages by `.github/workflows/hugo.yml`.

## Run it

```sh
hugo server
```

## Where things live

- `content/` the pages, in Markdown. New makes go in `content/makes/`.
- `layouts/` the templates.
- `assets/css/style.css` the whole design: cream fabric, pink thread, pattern-piece cards.
- `static/images/` photos, sized for the web, with location data removed.
- `static/fonts/` Fraunces, Nunito and Caveat, self-hosted (SIL Open Font License).

Icons are inline SVGs from [Lucide](https://lucide.dev) (ISC licence).
